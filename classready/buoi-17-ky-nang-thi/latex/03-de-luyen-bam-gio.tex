\section{HƯỚNG DẪN LÀM BÀI}

Bấm đồng hồ 30 phút. Ghi thời gian từng câu vào bảng ở cuối đề. Hết giờ dừng bút, kể cả còn câu chưa làm.

Mỗi câu có 4 phương án, chọn một. Câu nào quá 90 giây thì đánh dấu và chuyển sang câu sau.

\textbf{Câu 1.}

不等式 $3x^2 - 2x - 1 < 0$ 的解集是 ( )

A. $\left(-\dfrac{1}{3}, 1\right)$

B. $\left(-1, \dfrac{1}{3}\right)$

C. $(-\infty, -\dfrac{1}{3}) \cup (1, +\infty)$

D. $(-\infty, -1) \cup \left(\dfrac{1}{3}, +\infty\right)$

\textbf{Câu 2.}

复数 $z = i^{2025}$ 等于 ( )

A. 1

B. -1

C. $i$

D. $-i$

\textbf{Câu 3.}

$\int_0^1 (3x^2 + 1)\,dx$ 的值是 ( )

A. 1

B. 2

C. 3

D. 4

\textbf{Câu 4.}

某班级 20 名学生的数学考试成绩的平均分为 80 分，方差为 25。如果每名学生的成绩都增加 5 分，那么新成绩的平均分和方差分别是 ( )

A. 平均分 80, 方差 30

B. 平均分 85, 方差 30

C. 平均分 80, 方差 25

D. 平均分 85, 方差 25

\textbf{Câu 5.}

抛掷一枚均匀的硬币 3 次，恰好出现两次正面的概率是 ( )

A. $\dfrac{1}{8}$

B. $\dfrac{3}{8}$

C. $\dfrac{1}{2}$

D. $\dfrac{5}{8}$

\textbf{Câu 6.}

双曲线 $\dfrac{x^2}{16} - \dfrac{y^2}{9} = 1$ 的渐近线方程是 ( )

A. $y = \pm\dfrac{3}{4}x$

B. $y = \pm\dfrac{4}{3}x$

C. $y = \pm\dfrac{16}{9}x$

D. $y = \pm\dfrac{9}{16}x$

\textbf{Câu 7.}

已知球的方程为 $(x-1)^2 + (y+3)^2 + (z-5)^2 = 9$，则圆心坐标和半径分别为 ( )

A. $(-1, 3, -5), 3$

B. $(-1, 3, -5), 9$

C. $(1, -3, 5), 9$

D. $(1, -3, 5), 3$

\textbf{Câu 8.}

考虑一个随机变量 $X$，如果 $P(X > a) = 0.3$，那么 $P(X \le a)$ 等于 ( )

A. 0.3

B. 0.5

C. 0.7

D. 无法确定

\textbf{Câu 9.}

若 $z = 1 + i$，则 $z^8 = ( )$

A. 16

B. -16

C. $16i$

D. $2^{56}$

\textbf{Câu 10.}

抛物线 $y^2 = -12x$ 的焦点坐标是 ( )

A. $(3, 0)$

B. $(0, 3)$

C. $(-3, 0)$

D. $(0, -3)$

\textbf{Câu 11.}

复数 $z$ 满足 $z(1 + i) = 2i$，则 $z$ 等于 ( )

A. $1 - i$

B. $1 + i$

C. $-1 + i$

D. $-1 - i$

\textbf{Câu 12.}

已知集合 $A = \{a, b, c\}$，则下列不正确的关系是 ( )

A. $a \in A$

B. $\{a\} \subseteq A$

C. $\varnothing \subseteq A$

D. $c \notin A$

\textbf{Câu 13.}

设 $A = \{x \mid x^2 - (m + 10)x + 10m < 0\}$，若 $A = (7, 10)$，则 $m$ 的值是 ( )

A. 17

B. 10

C. 7

D. 3

\textbf{Câu 14.}

一个袋子里有 6 个白球和 3 个黑球。从中随机取出 2 个球，颜色相同的概率是 ( )

A. $\dfrac{1}{2}$

B. $\dfrac{3}{5}$

C. $\dfrac{2}{9}$

D. $\dfrac{3}{4}$

\textbf{Câu 15.}

某班级 10 名学生的体重（单位：kg）如下：50, 52, 55, 58, 60, 60, 62, 65, 68, 70。则这组数据的中位数是 ( )

A. 59

B. 60

C. 61

D. 62

\textbf{Câu 16.}

已知向量 $a = (1, -5)$，$b = (2, 4)$。求 $(a + b) \cdot (a - b)$ 等于 ( )

A. 12

B. -5

C. -6

D. 6

\textbf{Câu 17.}

如果集合 $A = \{1, a\}$，$B = \{1, 3, 6, 7, 9\}$，且 $A \subseteq B$，则实数 $a \ne 1$ 可以取值的个数是 ( )

A. 0

B. 3

C. 4

D. 5

\textbf{Câu 18.}

若关于 $x$ 的不等式 $x^2 + (m - 1)x + 1 > 0$ 对于一切实数 $x$ 恒成立，则实数 $m$ 的取值范围是 ( )

A. $(-1, 3)$

B. $[-1, 3]$

C. $(-\infty, -1) \cup (3, +\infty)$

D. $(-\infty, -1] \cup [3, +\infty)$

\textbf{Câu 19.}

空间中平面 $P_1: x + y + z = 1$ 与平面 $P_2: 2x + 2y + 2z = 3$ 的位置关系是 ( )

A. 重合

B. 垂直

C. 相交

D. 平行

\textbf{Câu 20.}

已知函数 $f(x) = x + \dfrac{1}{x}$，则当 $x < 0$ 时，$f(x)$ 的最大值为 ( )

A. 2

B. -2

C. 1

D. -1
