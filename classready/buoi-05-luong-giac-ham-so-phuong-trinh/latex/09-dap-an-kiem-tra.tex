\section{LỜI GIẢI NGẮN}

\textbf{Câu 1.} \texttt{CAE-M-CD4-08.4-M-050} — \textbf{Đáp án C}

Dùng công thức cung phụ: $\cos\left(x - \dfrac{\pi}{2}\right) = \sin x$.

\textbf{Câu 2.} \texttt{CAE-M-CD4-LX3-E-190} — \textbf{Đáp án A}

$\cos\left(-\dfrac{\pi}{3}\right) = \cos\dfrac{\pi}{3} = \dfrac{1}{2}$ vì $\cos$ là hàm chẵn.

\textbf{Câu 3.} \texttt{CAE-M-CD4-LX3-M-194} — \textbf{Đáp án B}

Công thức nhân đôi: $\cos 2\alpha = 1 - 2\sin^2\alpha = 1 - 2 \cdot \dfrac{9}{25} = \dfrac{7}{25}$.

\textbf{Câu 4.} \texttt{CAE-M-CD4-LX3-H-186} — \textbf{Đáp án D}

Với $\cos\alpha = -\dfrac{1}{3}$ và $\alpha$ ở phần tư thứ ba: $\sin\alpha = -\sqrt{1 - \dfrac{1}{9}} = -\dfrac{2\sqrt{2}}{3}$. Vậy $\sin 2\alpha = 2\sin\alpha\cos\alpha = 2 \cdot \left(-\dfrac{2\sqrt{2}}{3}\right) \cdot \left(-\dfrac{1}{3}\right) = \dfrac{4\sqrt{2}}{9}$.

\textbf{Câu 5.} \texttt{CAE-M-CD4-08.8-E-102} — \textbf{Đáp án A}

Công thức cộng: $\tan(\alpha + \beta) = \dfrac{\dfrac{1}{2} + \dfrac{1}{3}}{1 - \dfrac{1}{2} \cdot \dfrac{1}{3}} = \dfrac{5/6}{5/6} = 1$.

\textbf{Câu 6.} \texttt{CAE-M-CD4-LX3-H-157} — \textbf{Đáp án D}

Đồ thị $y = \sin x$ là hàm lẻ nên nhận gốc tọa độ làm tâm đối xứng.

\textbf{Câu 7.} \texttt{CAE-M-CD4-LX3-M-191} — \textbf{Đáp án B}

Đặt $t = \cos x$ với $t \in [-1, 1]$: $y = 1 - t^2 + 2t = -(t-1)^2 + 2 \le 2$. Giá trị lớn nhất là $2$ khi $t = 1$.

\textbf{Câu 8.} \texttt{CAE-M-CD4-LX3-H-195} — \textbf{Đáp án C}

$\cos^2 x - \sin^2 x = \cos 2x$, chu kỳ dương nhỏ nhất là $\dfrac{2\pi}{2} = \pi$.

\textbf{Câu 9.} \texttt{CAE-M-CD4-LX3-H-196} — \textbf{Đáp án D}

Hàm $y = 3\cos x$ có tập giá trị $[-3, 3]$.

\textbf{Câu 10.} \texttt{CAE-M-CD4-LX3-E-197} — \textbf{Đáp án C}

Vì $-1 \le \cos x \le 1$ nên $1 \le 2\cos x + 3 \le 5$. Tập giá trị là $[1, 5]$.

\textbf{Câu 11.} \texttt{CAE-M-CD4-LX2-M-124} — \textbf{Đáp án A}

$\cos 210^\circ = \cos(180^\circ + 30^\circ) = -\cos 30^\circ = -\dfrac{\sqrt{3}}{2}$.

\textbf{Câu 12.} \texttt{CAE-M-CD4-LX3-E-175} — \textbf{Đáp án B}

Với $a = b = 1$, tập giá trị của $a\sin x + b\cos x$ là $[-\sqrt{2}, \sqrt{2}]$.

\textbf{Câu 13.} \texttt{CAE-M-CD4-LX3-H-154} — \textbf{Đáp án D}

Cộng hai đẳng thức: $2\sin\alpha\cos\beta = \dfrac{4}{5}$ và $2\cos\alpha\sin\beta = \dfrac{2}{5}$. Chia vế theo vế: $\tan\alpha\cot\beta = 2$.

\textbf{Câu 14.} \texttt{CAE-M-CD4-LX3-E-159} — \textbf{Đáp án B}

$\alpha$ ở phần tư thứ hai nên $\cos\alpha < 0$. Từ $\sin^2\alpha + \cos^2\alpha = 1$ suy ra $\cos\alpha = -\dfrac{4}{5}$.

\textbf{Câu 15.} \texttt{CAE-M-CD4-LX3-M-192} — \textbf{Đáp án A}

$\tan 2\alpha = \dfrac{2\tan\alpha}{1 - \tan^2\alpha} = \dfrac{6}{1 - 9} = -\dfrac{3}{4}$.

\textbf{Câu 16.} \texttt{CAE-M-CD4-LX3-H-169} — \textbf{Đáp án C}

Biên độ bằng $2$ nên tập giá trị là $[-2, 2]$.

\textbf{Câu 17.} \texttt{CAE-M-CD4-LX3-E-165} — \textbf{Đáp án D}

Chia cả tử và mẫu cho $\cos\alpha$: $\dfrac{2\tan\alpha + 1}{\tan\alpha + 2} = \dfrac{15}{9} = \dfrac{5}{3}$.

\textbf{Câu 18.} \texttt{CAE-M-CD4-LX3-H-184} — \textbf{Đáp án C}

Công thức nhân đôi: $\sin 2\alpha = 2\sin\alpha\cos\alpha$, chia cho $\sin\alpha$ được $2\cos\alpha$.

\textbf{Câu 19.} \texttt{CAE-M-CD4-LX3-E-146} — \textbf{Đáp án B}

Vì $\sin x \le 1$ nên $y = 1 + \sin x \le 2$. Giá trị lớn nhất là $2$.

\textbf{Câu 20.} \texttt{CAE-M-CD4-LX3-E-176} — \textbf{Đáp án A}

$\sin x = \dfrac{1}{2}$ cho $x = \dfrac{\pi}{6}$ hoặc $x = \dfrac{5\pi}{6}$ trên $[0, 2\pi]$.

\textbf{Câu 21.} \texttt{CAE-M-CD4-08.7-M-093} — \textbf{Đáp án A}

Đạo hàm $y' = -\sin x$, tại $x = \dfrac{\pi}{3}$ có hệ số góc $-\dfrac{\sqrt{3}}{2}$. Đường thẳng vuông góc có hệ số góc $\dfrac{2}{\sqrt{3}}$. Viết phương trình qua $P\left(\dfrac{\pi}{3}, \dfrac{1}{2}\right)$ và rút gọn.

\textbf{Câu 22.} \texttt{CAE-M-CD4-LX3-M-193} — \textbf{Đáp án B}

Hệ số của $x$ là $\omega = 2$ nên chu kỳ là $\dfrac{2\pi}{2} = \pi$.

\textbf{Câu 23.} \texttt{CAE-M-CD4-LX3-E-145} — \textbf{Đáp án D}

$\sin x = -\dfrac{\sqrt{2}}{2}$ cho $x = \dfrac{5\pi}{4}$ hoặc $x = \dfrac{7\pi}{4}$ trên $[0, 2\pi]$.

\textbf{Câu 24.} \texttt{CAE-M-CD4-LX3-E-150} — \textbf{Đáp án C}

Giá trị nhỏ nhất của $a\sin x + b\cos x$ là $-\sqrt{a^2 + b^2} = -\sqrt{9 + 16} = -5$.
